# Goals

The outcomes this repository is chasing now.

**A run may propose a change here. Only a named human makes it current**, and a run never reads its
own draft as direction. Merging is the acceptance.

Current truth only. No issue numbers, no backlog, no tasks.

---

## Accepted

**None yet.** This file is new and nobody has accepted anything in it.

A run that reads this should say so and stop. That is the honest answer, not a gap to fill.

---

## Proposed

**A run drafted these from the doctrine and the open work. Nothing below binds anything.**

To accept one, move it above and say who accepted it and when.

### A person can run this without being told how

**Outcome.** Someone who never saw Foundry lands on the README and runs one command. They get back a
change they did not write.

**For.** A developer trying it for the first time. Nobody has yet.

**Evidence.** One person does it on a machine that is not this one, and says what they had to guess.

**Guardrails.** Nothing merges on its own. The first result is a proposal a person reads.

**Review.** When the first outsider tries it, or when a month passes with none.

### A repository can say what good means, and be held to it

**Outcome.** A repository states its own bar. Every change answers to the version signed off before
that change began.

**For.** Whoever is accountable for the code, and does not want to read every line.

**Evidence.** A change is refused for missing the bar, and the refusal names which part.

**Guardrails.** The producer never writes the bar it is judged by.

**Review.** When a run grades itself against something it wrote.

### What is believed stays in touch with what is true

**Outcome.** A belief that nothing has checked gets found and tested, before it costs a decision.

**For.** Anyone deciding what to build next.

**Evidence.** A belief moves from unknown to supported or contradicted, on evidence somebody else
produced.

**Guardrails.** A day that finds nothing publishes nothing. Missing evidence stays unknown.

**Review.** When a pass runs and no belief has changed state in a month.

---

## What this file is not

**Not a backlog.** Work lives in the work source.

**Not history.** What was dropped is dropped. History holds the rest.

**Not a task list.** A goal says what changes in the world, never who does what.
