# Consulting

What to send a second model, and what you already hold.

**101 consultations sit in the operator's `consultations/` directory and no rule governs any of
them.** This is that rule.

---

## Send what you have

**Before sending, ask one question: what do I already hold that this will otherwise redo?**

A consult spent 110 minutes running a timed pass of a suite. The same pass, timestamped line by
line, was already on disk from that morning. Nothing said so, so it measured again.

**Attach the artefact. Never describe it and hope.** A log, a verdict, a diff — the file is smaller
than the paragraph summarising it, and it cannot drift from what happened.

## One session, not four briefs

`claude -p --resume <session-id>` continues a print session. A second round then adds to the first
rather than restating it.

Four separate briefs went out on one subject here. Each re-explained the same repository, the same
numbers and the same rejected ideas. **Rounds two, three and four paid for context round one had
already sent.**

Ask for the model by alias — `--model fable`, not `claude-fable-5`. A pinned name goes stale the
day a version lands, and nothing tells you.

## A consult that cannot run has nothing to measure

Some sessions refuse execution. One reported the parse cost of a script as a third of a suite's
runtime; measured, it was under six per cent. **It could not run anything, and said so only when
pressed.**

So: give numbers rather than asking for them, and say how each was taken. A figure taken while
another suite was running is noise — mark it, or take it again.

## What the answer owes

**A recommendation, then the strongest case against it.** A round with nothing rejected is a round
that did not think, and thin answers arrive when nothing forces depth.

The consult that mattered here withdrew its own first claim. That is the shape to ask for.
