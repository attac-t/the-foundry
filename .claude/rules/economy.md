# Economy

Say more with less. Do more with less.

Both are **generative**, not corrective. Concision applied at the end is editing; applied at the start
it is design.

A polish pass removes words. It cannot remove the noun you invented, the fourth guard you bolted on,
or the abstraction you built for one caller — by then they are load-bearing, and cutting them is a
refactor nobody schedules. **The expensive waste is decided before the first character is written.**

**Not cryptic, and not fewer facts.** A technical distinction lost to brevity is a failure, not a
saving. Short and wrong is not economy.

The questions that make it generative are steps, so they live in a skill: `signal:economy`. Ask them
before writing — code, tests, prose, an issue, a PR, an RFC, a reply.
