## Principles

1. **Open with value** — What does the user get? Lead with that.
2. **Philosophy is short** — 2-3 sentences. If longer, you're preaching.
3. **Code blocks over tables** — Lists in code blocks are cleaner.
4. **Show structure** — Use consistent headers: Architecture, Commands, Installation.
5. **End with references** — Credit your sources.
6. **Closing line** — One memorable sentence.
