# Code of Conduct

This project adopts the [Contributor Covenant v2.1][covenant] as its code of
conduct. Read it — it is short, and it is the standard this project is held to.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

---

## In Short

Critique the code, never the person.

This project is opinionated about code. "This abstraction is wrong" is the point.
"You are wrong" is not. The difference is the whole standard.

Not acceptable, here or in any project space: harassment, personal attacks,
demeaning or discriminatory language, publishing others' private information.

---

## Reporting

Report a violation privately to the maintainers via
[GitHub's report abuse form](https://github.com/contact/report-abuse), or by
opening a [private security advisory][advisory] if you would rather keep it in
the repository.

[advisory]: https://github.com/attac-t/the-foundry/security/advisories/new

Reports are handled confidentially. Maintainers who fail to enforce this in good
faith answer to it themselves.

---

## Scope

Applies to every project space — issues, pull requests, discussions, commits —
and to anyone representing the project in public.
